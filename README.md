# liefergebiet

Die Lieferantenkarte zeigt nach einer Standortsuche die nächste in OpenStreetMap
gefundene Abholstation samt Adresse für jeden Lieferanten. Die Karten-Schalter
blenden jeweils Lieferant, Stationen und deren gebündelte Lieferradius-Fläche ein
oder aus; der bearbeitbare Radius gilt für alle gefundenen Stationen eines
Lieferanten. Die schriftliche Stationsliste bleibt unabhängig von den
Karten-Schaltern vollständig.
