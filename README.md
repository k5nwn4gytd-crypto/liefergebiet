# liefergebiet

Die Lieferantenkarte zeigt nach einer Standortsuche die nächste in OpenStreetMap
gefundene Abholstation samt Adresse für jeden Lieferanten. Alle Standorte werden
einzeln auf der Karte angezeigt. Lieferanten lassen sich über die Karten-Schalter
ein- und ausblenden; Radien sind standardmäßig ausgeblendet und können separat
eingeblendet werden.
Der bearbeitbare Radius gilt für alle Stationen eines Lieferanten. Die
schriftliche Stationsliste bleibt unabhängig von den Karten-Schaltern vollständig.
